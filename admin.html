2. 붙여넣기 (쿠팡 화면 표 또는 엑셀 피벗)

쿠팡 노트북의 엑셀에서 상품명(A열)과 수량(B열)을 함께 선택해 Ctrl+C → 아래 칸에 Ctrl+V 하세요. 선택한 차수의 머리글·소계와 모든 상품 행을 포함하세요. 전체 피벗을 복사해도 위에서 선택한 차수만 가져옵니다. 1차는 1-1·1-2 두 묶음을 합산해 1차로 등록하며, 한 묶음만 붙여넣으면 나머지 묶음은 기존 저장분을 유지합니다.

엑셀 없이 바로 붙여넣기: 쿠팡 WMS 출고 화면의 표(출고번호~배송구분)를 드래그해 복사(Ctrl+C)하고 아래 칸에 붙여넣으면 바코드별 수량을 자동 합산합니다. 위에서 선택한 날짜·차수로 등록되며, 100건씩 나뉘면 다음 페이지를 이어서 붙여넣으세요. 화면에 총 건수가 보이면 아래 소계 칸에 입력해 누락을 검산하세요.

3. 저장할 품목 확인

한 줄에 품목명 : 건수 형식입니다. 취소는 품목명 : 취소 1건 형식입니다. 같은 품목이 여러 줄이면 자동 합산합니다.

4. 취소 건 등록 (배치 생성 후 취소)

쿠팡 WMS 출고 관리에서 출고 상태를 출고 취소로 검색한 목록을 복사해 붙여넣으세요. 운송장 번호만 한 줄씩 붙여넣어도 됩니다(배치 생성 후 취소된 건만 골라 붙여넣으세요). 발주 등록 때 저장된 운송장 번호로 품목을 찾아 취소로 등록하고, 현장 화면에 취소와 실출고(누적−취소)를 보여 줍니다. 같은 번호를 다시 붙여넣어도 중복 차감하지 않습니다. 이 기능이 생긴 뒤 쿠팡 화면 표를 붙여넣어 저장한 건만 찾을 수 있습니다.
